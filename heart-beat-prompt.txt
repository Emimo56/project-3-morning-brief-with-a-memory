A few things this is doing on purpose:

"Read progress.md first" is the whole spine habit — skipping it is the #1 way this project fails silently.
The "skip anything already listed" line is what makes run two provably different from run one —
 that's your done-check.
The explicit no-new-commits case matters because a quiet day is a valid, useful log entry, not a failure.

Wrap this in your /schedule (Claude Code) or cron + opencode run call, then fire it twice with a
few commits in between to see the diff in behavior.
